# Auto Endcard Tool

Auto Endcard Tool 是一个面向 Windows 的批量视频片尾拼接工具。当前版本为 **v3.3 包边增强版**，提供图形界面，并随发布包附带 FFmpeg、FFprobe 和 Python/Tk 运行时，可直接运行，无需另外安装 Python。

工具支持两种工作方式：

- **常规模式**：识别原视频的画面比例，自动选择 16:9、1:1 或 9:16 片尾并拼接。
- **包边模式**：把原视频放入自定义的 1:1 或 9:16 背景画面中，再拼接相同比例的片尾；可以一次同时导出两种比例。

> 当前目录是已经构建好的 Windows 发布包，不包含 Python 源码、依赖清单或构建脚本。本文档根据现有可执行程序、配置文件和实际界面整理。

## 主要功能

- 递归扫描输入文件夹中的视频，并保留相对目录结构输出。
- 根据视频尺寸和旋转信息识别 16:9、1:1、9:16 画面比例。
- 为不同画面比例配置独立片尾。
- 支持视频片尾和静态图片片尾。
- 支持裁剪原视频开头和结尾后再拼接片尾。
- 支持 1:1、9:16 包边输出，可同时勾选两个规格。
- 包边背景支持静态图片或循环播放的视频。
- 可视化编辑视频框：新建框、移动、拖动四角或边线缩放。
- 框选比例可锁定为 16:9、1:1、9:16，或设为“不锁定”。
- 支持方向键 1 像素微调；按住 Shift 时以 10 像素微调。
- 支持 `contain` 和 `cover` 两种视频适配方式。
- 可生成包边首帧 PNG 预览，并自动打开查看。
- 支持保存和读取包边模板 JSON。
- 支持 FPS、CRF、编码速度、文件名后缀和覆盖策略设置。
- 提供处理进度、实时日志、停止请求和快速打开输出文件夹。
- 自动记忆上次使用的路径和导出参数。

## 运行环境

- Windows 64 位系统。
- 保持发布包目录结构完整，尤其不要单独移动 `AutoEndcardTool.exe`。
- `tools` 目录中需要存在 `ffmpeg.exe` 和 `ffprobe.exe`。程序也会尝试从系统 `PATH` 中查找它们。

当前本地发布包已经包含所需文件，双击 `AutoEndcardTool.exe` 即可启动。

Git 仓库会忽略整个 `tools` 目录。通过 Git 获取项目后，需要自行创建 `tools` 目录并放入 `ffmpeg.exe` 和 `ffprobe.exe`，或把二者加入系统 `PATH`。

## 快速开始

1. 在“处理模式”中选择“常规模式”或“包边模式”。
2. 选择原视频文件夹和输出文件夹。
3. 根据处理模式设置片尾：
   - 常规模式需要分别选择 16:9、1:1、9:16 片尾。
   - 包边模式需要勾选输出比例，并为每个勾选的比例选择背景和对应片尾。
4. 如有需要，设置开头/结尾裁剪、图片片尾时长、FPS、CRF、编码速度和文件名后缀。
5. 包边模式下可使用“编辑视频框”和“预览”检查画面布局。
6. 点击“开始批量处理”。

“停止”不会强制中断正在编码的文件；当前文件完成后，程序才会停止后续任务。

## 处理模式

### 常规模式

程序读取每个视频的实际尺寸，并考虑 90°/270° 旋转元数据，然后在以下目标规格中匹配最接近的比例：

| 比例 | 输出尺寸 | 使用的片尾 |
| --- | ---: | --- |
| 16:9 | 1920 × 1080 | 16:9 片尾 |
| 1:1 | 1080 × 1080 | 1:1 片尾 |
| 9:16 | 1080 × 1920 | 9:16 片尾 |

原视频会等比缩放到目标画布中，空余区域补黑。无法在容差范围内匹配上述三种比例的视频会被跳过，并在日志中显示原因。

### 包边模式

包边模式可导出 1:1、9:16，或同时导出两种规格。每种规格都可以独立配置：

- 背景图片或背景视频。
- 对应比例的片尾。
- 原视频在背景上的位置和尺寸。

背景视频会循环到原视频片段结束；背景音频不会写入输出。建议背景素材本身使用对应的目标比例，以免出现补黑区域。

“视频放入框中的方式”包含：

- `contain`：完整显示原视频，比例不一致时在视频框内部补黑。
- `cover`：填满视频框，超出部分会被裁切。

## 视频框编辑与预览

点击“编辑 1:1 视频框”或“编辑 9:16 视频框”可以打开布局编辑器：

- 在空白处拖动可以创建新的视频框。
- 在已有框内部拖动可以移动位置。
- 拖动四角或边线可以调整尺寸。
- 方向键每次移动 1 像素，Shift + 方向键每次移动 10 像素。
- “重置默认位置”会按默认 16:9 源画面重新计算居中布局。

布局使用相对于目标画布的归一化坐标保存：

- `x_pct`、`y_pct`：视频框左上角的位置比例。
- `w_pct`、`h_pct`：视频框宽度和高度比例。
- 所有值限制在 `0.0` 到 `1.0` 范围内。

预览源的选择顺序为：

1. “预览源视频”中手动选择的文件。
2. 原视频文件夹内扫描到的第一个视频。

预览结果保存为输出目录中的 `preview_1x1.png` 或 `preview_9x16.png`。未设置输出目录时，保存到程序目录下的 `output` 文件夹。

## 支持的素材格式

### 原视频

`.mp4`、`.mov`、`.m4v`、`.mkv`、`.avi`、`.webm`

### 片尾

- 视频：`.mp4`、`.mov`、`.m4v`、`.mkv`
- 图片：`.png`、`.jpg`、`.jpeg`、`.webp`、`.bmp`、`.gif`

图片类片尾会按照“静态图片片尾时长”循环输入并截取到设定时长。

### 包边背景

- 视频：`.mp4`、`.mov`、`.m4v`、`.mkv`
- 图片：`.png`、`.jpg`、`.jpeg`、`.webp`、`.bmp`、`.gif`

## 导出设置

| 设置 | 可选值或含义 | 程序默认值 |
| --- | --- | ---: |
| 裁剪开头/秒 | 从原视频开头移除的时长 | `0.0` |
| 裁剪结尾/秒 | 从原视频结尾移除的时长 | `0.0` |
| 静态图片片尾时长/秒 | 图片片尾持续时间 | `3.0` |
| FPS | `24`、`25`、`30`、`60` | `30` |
| CRF 画质 | `16`、`18`、`20`、`22`、`24`；越小画质越高、文件越大 | `18` |
| 编码速度 | `fast`、`medium`、`slow` | `medium` |
| 文件名后缀 | 添加到原文件名后 | `_endcard` |
| 覆盖同名输出 | 开启时覆盖，关闭时跳过已存在文件 | 开启 |

如果裁剪后剩余的原视频不超过约 `0.05` 秒，该文件会被跳过。

## 输出规则

程序始终输出 MP4 文件，并保留输入目录下的相对文件夹结构。输出文件夹可以放在输入文件夹内部，程序会排除输出目录，避免再次扫描已经生成的视频；但不要把输入文件夹和输出文件夹设置为同一个目录。

默认命名示例：

```text
输入：clips/level-01/demo.mov

常规模式：
output/level-01/demo_endcard.mp4

包边模式：
output/level-01/demo_endcard_1x1.mp4
output/level-01/demo_endcard_9x16.mp4
```

编码参数固定为：

- 视频：H.264 / `libx264`，像素格式 `yuv420p`。
- 音频：AAC 192 kbps、48 kHz、双声道。
- MP4 启用 `faststart`，便于网络播放。

原视频或片尾没有音轨时，程序会自动补充静音轨道，以保证音视频可以正常拼接。

## 配置与模板

### 自动配置

程序启动时读取根目录下的 `auto_endcard_config.json`，开始处理和正常退出时会更新该文件。配置内容包括：

- 输入、输出、预览源和三个片尾路径。
- 处理模式和包边背景。
- 裁剪、图片时长、FPS、CRF、编码速度、后缀和覆盖策略。
- 包边输出开关、适配方式、比例锁定和视频框布局。

配置文件保存的是绝对路径，分享发布包或提交配置前请先检查并移除内部路径、网络地址等信息。

### 包边模板

“保存模板”生成独立的 JSON 文件，主要保存可复用的包边方案：

- 处理模式。
- 1:1/9:16 输出开关。
- 背景和对应片尾路径。
- `contain`/`cover` 适配方式。
- 框选比例锁定方式。
- 1:1/9:16 视频框布局。

模板不包含输入目录、输出目录、16:9 片尾、裁剪和编码参数；这些内容由自动配置文件保存。

## 目录结构

```text
AutoEndcardTool/
├─ AutoEndcardTool.exe          # 主程序
├─ auto_endcard_config.json     # 运行后自动生成的用户配置（Git 已忽略）
├─ tools/                       # 本地工具目录（Git 已忽略）
│  ├─ ffmpeg.exe                # 视频编码与合成
│  └─ ffprobe.exe               # 媒体信息检测
├─ _internal/                   # Python、Tk 和运行时依赖
└─ .preview_cache/              # 布局编辑器生成的背景预览缓存
```

`.preview_cache` 是可再生成的缓存目录；`_internal` 和 `tools` 则是程序正常运行所必需的目录。

## 处理流程概览

1. 使用 FFprobe 读取视频尺寸、时长、音轨和旋转信息。
2. 递归扫描并过滤支持的视频文件。
3. 按设置裁剪原视频首尾。
4. 常规模式匹配目标比例；包边模式合成背景和视频框。
5. 将片尾缩放到目标尺寸并直接拼接。
6. 使用 FFmpeg 编码 MP4，更新进度并记录成功、跳过或失败信息。

## 使用注意事项

- 为保证片尾不被拉伸，建议片尾素材预先制作成对应的目标比例和尺寸。
- 输出目录不要与输入目录完全相同；使用输入目录下的独立 `output` 子目录是安全的。
- 文件名相同但扩展名不同的输入文件，如果位于同一目录，可能生成相同的输出文件名；请使用不同文件名或关闭覆盖并检查日志。
- “停止”是安全停止：不会终止当前 FFmpeg 进程，而是在当前文件处理完成后停止。
- 如果提示找不到 FFmpeg/FFprobe，请检查 `tools` 目录，或把二者加入系统 `PATH`。
- 当前发布包使用软件编码 `libx264`，没有提供界面选项切换 GPU 硬件编码器。
